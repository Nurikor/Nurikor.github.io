# Визитка (шаблон) для GitHub Pages

Это минимальный статичный шаблон визитки/портфолио для публикации через GitHub Pages. Шаблон не требует бэкенда — просто отредактируйте `index.html` и загрузите в репозиторий.

Что и где править:
- `index.html`: основной файл — измените `Ваше Имя`, `Кто вы`, ссылки в разделе "Социальные сети", список проектов и контакты.
- `css/style.css`: стили — можете поменять цвета и шрифты.
- `assets/avatar-placeholder.svg`: замените на ваш аватар (с тем же именем или измените путь в `index.html`).

Деплой на GitHub Pages:
1. Создайте репозиторий с именем `yourusername.github.io` или любой репозиторий и включите Pages из ветки `main` (или `gh-pages`).
2. Закоммитьте и запушьте файлы в репозиторий.

Пример команд (локально):
```bash
git init
git add .
git commit -m "Add personal card template"
git branch -M main
git remote add origin https://github.com/yourusername/yourrepo.git
git push -u origin main
```

После этого откройте настройки репозитория → Pages и выберите ветку (обычно `main`) для публикации. Через минуту ваша страница будет доступна по адресу, указанному в настройках Pages.

Если хотите, помогу заменить данные на ваши и настроить деплой.
